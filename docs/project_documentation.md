# CineVault Project Documentation

## 1. Objective

To develop a desktop application that manages a movie collection and analyzes the user's viewing preferences.

## 2. Core Operations

1. Add movie
2. Update movie
3. Delete movie
4. Search movie
5. Filter movie
6. Calculate summaries
7. Analyze preferences
8. Compare viewing data
9. Generate visual reports

## 3. Data Fields

ID, title, genre, rating, year, language, duration, status, favorite, date added, date watched and notes.

## 4. Analysis

The application calculates total movies, average rating, status counts, genre frequency, language frequency, preferred genre, preferred language, yearly trends and rating distribution.

## 5. Visual Reports

1. Genre distribution bar chart
2. Viewing status pie chart
3. Rating distribution bar chart
4. Yearly viewing trend line chart

## 6. Validation

The application validates movie title, rating, release year, duration, genre, language and status.

## 7. Exception Handling

File errors, invalid data and missing movie records are handled with exceptions and user-friendly messages.
